# הצ׳ייסר — משחק טריוויה משפחתי

משחק טריוויה בעברית בהשראת התוכנית *הצ׳ייסר*, לערב משחקים משפחתי.
1–4 שחקנים, שלושה סבבים, צ׳ייסר ממוחשב בשלוש רמות קושי — והכול רץ בדפדפן,
בקובץ HTML אחד, בלי שרת ובלי התקנה.

## איך מפעילים

**הדרך הפשוטה:** להוריד את `index.html` ולפתוח אותו בדפדפן בלחיצה כפולה.

**דרך שרת מקומי** (מומלץ אם רוצים לפתוח גם מהטלפון באותה רשת):

```bash
python3 -m http.server 8000
# ואז: http://localhost:8000/
```

**GitHub Pages:** ב-Settings → Pages, לבחור את הענף ואת התיקייה הראשית.
`index.html` בשורש הוא כל מה שצריך.

המשחק תוכנן למסך אחד משותף — מחשב נייד או טלוויזיה במרכז החדר.
הוא מתאים את עצמו גם למסך טלפון (עד רוחב 360 פיקסלים).

## מהלך המשחק

### סבב 1 — צבירת כסף
לכל שחקן/ית 60 שניות. השאלה מוצגת, עונים בקול, ומי שמחזיק במסך לוחץ
**נכון** / **לא נכון** / **דלג**. כל תשובה נכונה שווה 1,000 ₪ לקופה האישית.
שאלה שדולגה חוזרת בהמשך הסבב.

קיצורי מקלדת: `←` נכון · `→` לא נכון · `רווח` דילוג.

### סבב 2 — המרדף האישי
הצ׳ייסר מציע שלוש אפשרויות:

| הצעה | הסכום | מיקום התחלה | תשובות עד הבית |
|---|---|---|---|
| נמוכה | כרבע מהקופה | צעד אחד קרוב יותר לבית | 3 |
| הסכום שצברתם | הקופה כפי שהיא | אמצע הלוח | 4 |
| גבוהה | פי 4–8 מהקופה, לפי רמת הצ׳ייסר | צעד אחד קרוב יותר לצ׳ייסר | 5 |

הלוח בנוי מ-7 שלבים בין הצ׳ייסר לבית. שאלות אמריקאיות עם שלוש אפשרויות:
ברגע שאחד הצדדים נועל תשובה מתחילה ספירה של 5 שניות לצד השני, ומי שלא נעל
בזמן נחשב כמי שטעה. תשובה נכונה = צעד קדימה. מי שמגיע הביתה מכניס את הסכום
לקופה המשותפת; מי שנתפס יוצא מהמשחק.

קיצורי מקלדת: `1` / `2` / `3` לבחירת תשובה.

### סבב 3 — המרדף הסופי
כל מי ששרד משחק יחד על הקופה המשותפת, עם יתרון פתיחה של צעד אחד לכל שחקן ששרד.
שתי דקות לקבוצה לצבור צעדים, ואז שתי דקות לצ׳ייסר להשיג אותה.
**דחיפה לאחור:** כשהצ׳ייסר טועה, השעון נעצר והמשפחה מקבלת 7 שניות לענות על
אותה שאלה — תשובה נכונה דוחפת אותו צעד אחורה.

אם הצ׳ייסר משיג את הקבוצה, הקופה נשארת אצלו.

## רמות הצ׳ייסר

| רמה | דיוק | מהירות תשובה | כפולת ההצעה הגבוהה |
|---|---|---|---|
| קל — "הצ׳ייסר המתלמד" | ~60% | 5.0 שניות | ×4 |
| בינוני — "הצ׳ייסר המקצוען" | ~75% | 4.0 שניות | ×6 |
| קשה — "מצב איתי הרמן" | ~90% | 3.2 שניות | ×8 |

לכל רמה יש גם חוזקות וחולשות לפי נושא — ובשאלות משפחתיות הצ׳ייסר גרוע במיוחד,
כפי שמתבקש.

**מנחה אנושי:** במקום הצ׳ייסר הממוחשב אפשר לבחור שאחד מבני המשפחה ישחק את
הצ׳ייסר. במרדף האישי מוצג לו לוח נפרד לבחירת התשובה, ובמרדף הסופי הוא מסמן
בעצמו אם הצ׳ייסר צדק או טעה.

## השאלות

המשחק מגיע עם כ-280 שאלות בעברית בשישה נושאים: ידע כללי, תרבות ישראלית,
קולנוע וטלוויזיה, מדע וטבע, היסטוריה, וילדים ודיסני. אפשר לבחור אילו נושאים
ישתתפו במשחק.

**טריוויה משפחתית:** בתפריט הראשי אפשר להוסיף שאלות משלכם — שאלה, תשובה נכונה
ושתי תשובות שגויות. השאלות נשמרות ב-`localStorage` של הדפדפן (כלומר במכשיר הזה
בלבד), ואפשר לייצא אותן לקובץ JSON ולטעון אותן במכשיר אחר.

## מבנה הקוד

הכול בקובץ אחד, `index.html`, מחולק למקטעים מסומנים:

| מקטע | תוכן |
|---|---|
| `<style>` | ערכת העיצוב — רקע אולפן, לוח המרדף, טיימרים, אנימציות |
| `RAW` | מאגר השאלות: `[שאלה, תשובה נכונה, מסיח, מסיח]` |
| `Sound` | מנוע קול מסונתז ב-Web Audio API — בלי קובצי שמע |
| `Clock` / `live` | טיימרים שנרשמים מרכזית ומתנקים במעבר בין מסכים |
| `state` / `Screens` | מצב המשחק וניתוב המסכים (`go('screen')`) |

העיצוב משתמש ב-Tailwind מ-CDN לפריסה, אבל כל ערכת הצבעים, הלוח והאנימציות
כתובים ב-CSS מקומי — אם אין אינטרנט המשחק עדיין נראה ופועל כשורה.
הקול כולו מסונתז בזמן אמת, כך שאין נכסים חיצוניים לטעון.

## בדיקות

```bash
node tests/smoke.mjs
```

מריץ משחק שלם בדפדפן אמיתי (Playwright + Chromium) בשני רוחבי מסך: מוסיף שאלה
משפחתית, משחק סבב צבירה, בודק את שלוש ההצעות, מנצח מרדף אחד ומפסיד באחר, מגיע
למרדף הסופי ולמסך התוצאות — ומוודא שאין שגיאות קונסולה. צילומי המסך נשמרים
ב-`.screenshots/`.

הבדיקה טוענת את המשחק עם `?fast=1` — דגל פיתוח שמקצר את כל הטיימרים
(8 שניות לסבב הצבירה במקום 60). שימושי גם כשרוצים לבדוק שינוי ידנית בלי לחכות.
